# Suggest thoughtful questions

Follow [vault access](../../references/vault-access.md). When the user supplies enough context in the request, work from it without scanning unrelated notes. Otherwise use the retrieval process in [read-person-notes](../read-person-notes/SKILL.md) to establish relevant evidence. Read the [question guide](references/question-guide.md) before choosing suggestions.

Use the user's occasion, relationship, and desired tone when given. A casual coffee can start lightly. Do not require an intimacy rating or a long intake form. If there are no notes, offer clearly labeled general questions and explain that they are not personalized.

Select two questions by default, or the number the user requests. Make them different enough to offer a real choice. Favor a remembered detail or an invitation to tell a story. Keep each question short enough to say naturally, with one main idea. A more personal follow-up should depend on what the friend actually shares, not on a predicted response.

Under each question, give a brief reason it fits and cite the source for any factual premise. Label user-supplied context as such if it has no file. For example, a ceramics workshop supports asking how preparation is going; it does not establish that the friend is worried or needs help.

Check every suggestion for an assumed outcome, unresolved date, rejected claim, hidden feeling, or private information learned from someone else. Rephrase or omit the question when that premise is unsupported. The explanatory text must pass the same check.

Frame suggestions as options. Give the friend room to decline, change the subject, or stay with something light. Encouragement, shared enjoyment, and attentive listening are valid aims. Do not optimize for extracting secrets, manufacturing closeness, or making someone like the user.

Return suggestions in chat unless a card was requested. A complete answer has usable questions, source support for their premises, and no promised social outcome. Do not send a message or save a new memory of the friend's hypothetical answer.
