# Social Navigator

A free Markdown vault for notes about friends and preparation before meeting them. Edit it in Obsidian and open the same folder in Codex or Claude Code.

[Try the website demo](https://social-navigator-notes.marcusgohtx.chatgpt.site/) · [Download the starter vault](https://social-navigator-notes.marcusgohtx.chatgpt.site/downloads/social-navigator-starter.zip) · [Start here](START_HERE.md)

START_HERE.md is the only guide needed for everyday use. Conversations holds your notes, Context holds sourced summaries, and Prep holds meeting preparation. Templates and five agent skills are included. Everything under Examples is fictional.

## Contribute

Open an issue for a bug or suggestion, or fork this repository and send a pull request. Improvements to instructions, templates, examples, and skill behavior are welcome.

- Use fictional notes in issues, examples, and tests. Keep personal notes in your private vault.
- For skill changes, run the relevant [trial cases](docs/SKILL-TRIALS.md) with your agent and report its name, version, prompt, and result. The [existing results](docs/SKILL-TEST-RESULTS.md) describe what has been tested.
- Check relative links and preserve the distinction between source notes and agent-maintained context.

The project is an early prototype. Installed-plugin discovery still needs testing. The [development plan](docs/development/PLAN.md) records the scope. Agent support files are read by their hosts.
