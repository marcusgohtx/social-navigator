# Start here

1. Open this folder as a vault in Obsidian.
2. Write a note about a friend in **Conversations**. Fragments and uncertain recollections are fine.
3. Open this same folder as a project in Codex or Claude Code. Ask:

   > Prepare me for coffee with [name] on [date].

4. Read the saved brief in **Prep**. After meeting, add another conversation note.

The agent reads its project instructions in the background. You do not need to ask it to read AGENTS.md or CLAUDE.md. If your host does not load project instructions, use the [agent setup guide](docs/SKILLS.md).

## Try the fictional example

> Use only Examples/Conversations. Prepare me for the 12 October 2026 meeting with Maya. Save a fictional demo brief in Prep and leave the examples unchanged.

This replays a historical example. Your own notes belong in Conversations; the fictional notes stay in Examples.

## Folders

- **Conversations** — your raw notes.
- **Context** — source-linked notes about people and shared places, maintained by the agent on request.
- **Prep** — a dated brief for a meeting.
- **Templates** — optional reusable notes for conversations, context, and prep. To insert them with Obsidian, enable its core Templates plugin and set the template folder to Templates. You can also copy a template manually.

For a quick answer, ask “What did I promise Maya?” or “What could I ask Maya next time?” For context upkeep, ask “Refresh context from my new notes.”

There is no background agent. Ask for a fresh brief before each meeting. Files stay in your folder; a cloud agent may send the notes it reads to its provider. Your sync and history settings also apply.
